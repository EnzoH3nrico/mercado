*REST API MERCADO*

Projeto desenvolvido com *Java SpringBoot* que consome *API REST*, aplicando conceitos como *CRUD*, além de boas práticas com *Annotation e Beans*.
Desenvolvi este projeto para armazenar dados básicos, como item, marca e preco, e dados complexos, como nome, cnpj e telefone do fornecedor.

---

## Objetivo do projeto
Demonstrar como:

* Consumir uma API REST
* Integrar MySQL ao SpringBoot
* Uilizar CRUD no projeto
* Atualizar dados com FlyWay

---

##Tecnologias usadas

* **Java 17+**
* **Spring Framework**
* **MySQL**
* **Maven**
